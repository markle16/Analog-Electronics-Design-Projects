# Welcome to my Analog Electronics Design Showcase!
This repository showcases four projects completed of the course **ECE 2EI4 - Microelectronics Circuits & Devices I** at McMaster University: a DC power supply, an  unity-gain amplifier, transistor-level logic gate, and a data converter.

The motivation behind these projects was to connect classroom theory with practical circuit design, exploring how diodes, transistors, and operational amplifiers can be used to build functional electronic systems. Together, the projects cover power conversion and regulation, transistor switching, signal amplification, CMOS logic, and digital-to-analog conversion.

Through circuit analysis, simulation, and hands-on testing, these projects helped me develop a stronger understanding of component selection, design trade-offs, and the differences between ideal circuit behaviour and real-world performance. They also provided experience troubleshooting circuits and evaluating whether a design meets its intended requirements.

Detailed descriptions of each project, including schematics, design calculations, simulation results, and experimental measurements, will be added in a separate project folder

- Project 1: DC Power Supply
- Project 2: Unity-gain Amplifier
- Project 3: CMOS XOR Gate
- Project 4: 3-bit Digital-to-Analog Converter
